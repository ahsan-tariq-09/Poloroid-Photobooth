The reference images are design documentation. The website's layout, icons, frame illustrations, and decoration geometry are original HTML/CSS/SVG/Canvas work. DM Serif Display, DM Sans and DM Mono are bundled locally for predictable rendering without third-party font requests.

The editor starts with a complete sample Polaroid. The sample image is saved at `public/sample-coast.png`, generated using the built-in image-generation tool. It is a demo scene, not a user photograph.

Generation prompt:

Warm imperfect nostalgic 1970s vacation snapshot, visible fine film grain, subtle faded color, soft light and authentic natural composition. No people, no text, no border, no watermarks.
